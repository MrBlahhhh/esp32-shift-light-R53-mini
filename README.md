ESP32 CAN Bus with SN65HVD230, WS2812B LEDs, and ESP-NOW
This project uses an ESP32 to interface with a CAN bus via the SN65HVD230 transceiver, control WS2812B addressable LEDs for visual feedback, and communicate wirelessly using ESP-NOW.
Hardware Requirements

ESP32 development board (e.g., ESP32 DevKit)
SN65HVD230 CAN transceiver module (e.g., Waveshare or similar breakout)
WS2812B addressable LED strip
